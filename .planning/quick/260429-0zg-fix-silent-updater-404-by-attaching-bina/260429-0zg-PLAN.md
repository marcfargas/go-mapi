**Edit A — Insert a new "Stage release binaries (signed-or-unsigned)" pwsh step**
immediately AFTER the existing `Generate SHA256SUMS.txt` step (currently around
line 216) and BEFORE the existing `Attach installer + SHA256SUMS.txt to GitHub
Release` step (currently around line 218). Use this exact step body:

```yaml
      - name: Stage release binaries (signed-or-unsigned)
        shell: pwsh
        run: |
          # REL-09 fix (todo 2026-04-28): the Phase 11.1 silent updater
          # (src/app/updates_silent.go) downloads go-mapi.exe + go-mapi-x64.dll +
          # go-mapi-x86.dll from releases/latest/download/<name>. They were never
          # attached to the release until now, causing 404 on every silent run.
          # Pick the signed branch when SignPath ran, else fall back to the
          # unsigned staged/ tree. Filenames must match the SHA256SUMS.txt
          # manifest (already produced above).
          $src = if (Test-Path 'staged-signed') { 'staged-signed' } else { 'staged' }
          New-Item -ItemType Directory -Force release-bins | Out-Null
          Copy-Item "$src/go-mapi.exe"     release-bins/
          Copy-Item "$src/go-mapi-x64.dll" release-bins/
          Copy-Item "$src/go-mapi-x86.dll" release-bins/
          Write-Host "Staged release binaries from ${src}:"
          Get-ChildItem release-bins | ForEach-Object { Write-Host "  $($_.Name)  $($_.Length) bytes" }
```

Notes / rationale:
- No `if:` guard — this step must run on BOTH the signed and unsigned branches
  (the SignPath steps already gate themselves; the staged-signed/ vs staged/
  selection happens at runtime via `Test-Path`).
- Step runs unconditionally on every workflow trigger (push to v* tag,
  workflow_dispatch). On `dry_run` the files are still staged but the release
  step below remains skipped (its existing `if:` guard handles that).
- The pwsh `Get-ChildItem` echo is for CI log clarity — keep it.

**Edit B — Extend the `files:` block of the existing
`Attach installer + SHA256SUMS.txt to GitHub Release` step** (currently around
line 218) to include the three new assets. The final step must read:

```yaml
      - name: Attach installer + SHA256SUMS.txt to GitHub Release
        if: ${{ github.event_name == 'push' && (github.event.inputs.dry_run != 'true') }}
        uses: softprops/action-gh-release@v2
        with:
          files: |
            ${{ steps.final.outputs.path }}
            SHA256SUMS.txt
            release-bins/go-mapi.exe
            release-bins/go-mapi-x64.dll
            release-bins/go-mapi-x86.dll
          draft: false
          prerelease: false
          body_path: .github/release-template.md
```
