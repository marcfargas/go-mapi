# Plan 03-01: Inno Setup installer script

## Goal

Write `src/installer/go-mapi.iss` (Inno Setup 6) that compiles to a single `go-mapi-setup.exe` installer producing the end state described in Phase 3 CONTEXT decisions D-05..D-16: binaries in `%ProgramFiles%\go-mapi`, MAPI handler registered under HKLM, previous-default backup JSON under `%ProgramData%\go-mapi\uninst\`, one shared manifest file under `%ProgramData%\go-mapi\`, five browser registry trees pointing at it, and a clean uninstall round-trip.

## Tasks

### Task 1: Create `src/installer/` directory and `go-mapi.iss`

- `DisableDirPage=yes` (single UAC prompt — user should not pick install dir)
- `DisableProgramGroupPage=yes`
- `DisableWelcomePage=no`

- `OutputBaseFilename=go-mapi-setup`

**`[Files]`**
- Source: `{#SourcePath}\..\..\src\interceptor\build\bin\go-mapi.dll`; DestDir: `{app}`; Flags: `ignoreversion`
- Source: `{#SourcePath}\..\..\src\native-host\build\go-mapi-host.exe`; DestDir: `{app}`; Flags: `ignoreversion`
- Source: `{#SourcePath}\..\..\src\native-host\manifests\com.gomapi.host.chrome.json.tmpl`; DestDir: `{tmp}`; Flags: `dontcopy` — the template is embedded in the installer and extracted to the temp directory on install, then the Pascal code in `[Code]` reads it, substitutes placeholders, and writes the final manifest.

  - Root: HKLM; Subkey: `SOFTWARE\Chromium\NativeMessagingHosts\com.gomapi.host`; ...
  - Root: HKLM; Subkey: `SOFTWARE\Microsoft\Edge\NativeMessagingHosts\com.gomapi.host`; ...
  - Root: HKLM; Subkey: `SOFTWARE\BraveSoftware\Brave-Browser\NativeMessagingHosts\com.gomapi.host`; ...
  - Root: HKLM; Subkey: `SOFTWARE\Vivaldi\NativeMessagingHosts\com.gomapi.host`; ...

**`[Dirs]`**
- Name: `{commonappdata}\go-mapi`; Flags: `uninsneveruninstall` (we explicitly delete in Pascal code when empty)
- Name: `{commonappdata}\go-mapi\uninst`; Flags: `uninsneveruninstall`

**`[Code]` (Pascal Script)**

Constants near the top:
```
const
  GO_MAPI_EXTENSION_ID = 'PLACEHOLDER_EXTENSION_ID_32CHR';
  MAIL_CLIENTS_KEY = 'SOFTWARE\Clients\Mail';
```

Helper functions:
- `function RenderManifest(const TemplatePath, HostExePath, ExtensionId: String): String;`
  - Reads the template via `LoadStringFromFile`, performs `StringChange(HostPathEscaped, '\', '\\')` for JSON-safe backslashes, then two `StringChange` calls to replace `{{HOST_PATH}}` and `{{EXTENSION_ID}}`, returns the rendered string.
- `procedure BackupPreviousMailClient();`
  - Reads `HKLM\SOFTWARE\Clients\Mail` `(Default)` via `RegQueryStringValue`. If the current value is empty OR equals `go-mapi`, skip backup (preserves existing backup on upgrade). Otherwise builds a JSON string `{"previousClient":"<value>","backedUpAt":"<ISO-8601-timestamp>"}` using `GetDateTimeString('yyyy-mm-dd''T''hh:nn:ss', #0, #0) + 'Z'` and writes it to `{commonappdata}\go-mapi\uninst\previous-mail-client.json` via `SaveStringToFile`. If the backup file already exists, do NOT overwrite.
- `procedure SetGoMapiAsDefaultMailClient();`
  - Writes `(Default)` = `go-mapi` to `HKLM\SOFTWARE\Clients\Mail` via `RegWriteStringValue`.
- `procedure WriteSharedManifest();`
  - Calls `ExtractTemporaryFile('com.gomapi.host.chrome.json.tmpl')` to materialize the template. Calls `RenderManifest` with the extracted path, `ExpandConstant('{app}\go-mapi-host.exe')`, and `GO_MAPI_EXTENSION_ID`. Saves the result to `{commonappdata}\go-mapi\com.gomapi.host.json` via `SaveStringToFile` with UTF-8 encoding (third `SaveStringToFile` parameter = `False` for no BOM; match `install.ps1`'s `Encoding UTF8 -NoNewline`).
- `procedure RestorePreviousMailClient();` (uninstall-time)
  - Reads the JSON backup file, extracts the `"previousClient":"..."` value via simple string parsing (Pascal Script has no JSON parser — use `Pos` and `Copy` to find the value between `"previousClient":"` and the closing quote). Checks if `HKLM\SOFTWARE\Clients\Mail\<previousClient>` subkey exists; if yes, writes `(Default)` = `<previousClient>` back. If the backup JSON is missing or the previous client subkey is gone, tries fallbacks: `Microsoft Outlook`, `Outlook`, `Windows Mail`. If none exist, writes an empty string to `(Default)`.
- `procedure CleanTempGoMapi();` (uninstall-time)
  - Best-effort deletion of `%TEMP%\go-mapi` via `DelTree(ExpandConstant('{tmp}\..\go-mapi'), True, True, True)` — note `{tmp}` inside Pascal code at install time is the installer's temp, not `%TEMP%`; use `GetEnv('TEMP')` or `ExpandConstant('{%TEMP}')` instead. The safe approach: `DelTree(ExpandConstant('{userappdata}\..\..\Local\Temp\go-mapi'), True, True, True)` — but the installer runs as admin, so this is SYSTEM's profile. Use `GetEnv('TEMP')` concatenated with `\go-mapi`. Wrap in try/except semantics via checking existence with `DirExists` first. This step is best-effort per D-15.

Event function hooks:
- `procedure CurStepChanged(CurStep: TSetupStep);`
  - On `ssInstall`: call `BackupPreviousMailClient`.
  - On `ssPostInstall`: call `WriteSharedManifest`; call `SetGoMapiAsDefaultMailClient`.
- `procedure CurUninstallStepChanged(CurUninstallStep: TUninstallStep);`
  - On `usUninstall`: read the current `HKLM\SOFTWARE\Clients\Mail\(Default)`; if it equals `go-mapi`, call `RestorePreviousMailClient`. Delete `{commonappdata}\go-mapi\com.gomapi.host.json` via `DeleteFile`. Delete the backup JSON. Delete `{commonappdata}\go-mapi\uninst` via `RemoveDir` (empty). Delete `{commonappdata}\go-mapi` via `RemoveDir` (empty). Call `CleanTempGoMapi`.

Write the `.iss` file so `iscc.exe` accepts it with:
```
iscc /DGOMAPIVersion=1.0.0 src\installer\go-mapi.iss
```
producing `src\installer\dist\go-mapi-setup.exe`.

Also create `src/installer/README.md` (~40 lines) documenting: (a) how to build locally (`iscc /DGOMAPIVersion=<ver> go-mapi.iss`), (b) the required binary source paths (`src/interceptor/build/bin/go-mapi.dll`, `src/native-host/build/go-mapi-host.exe`) that must exist before compile, (c) how the Pascal Script handles manifest rendering and previous-client backup, (d) the `GO_MAPI_EXTENSION_ID` constant and when to update it (when Chrome Web Store listing is published), (e) pointer to the Pester smoke test in Plan 03-05.
</action>

## Notes

- This plan does NOT run `iscc.exe`. Compilation verification happens in Plan 03-05 (Pester smoke test workflow) or manually on a Windows host with Inno Setup 6 installed.
- The Pascal script inside `[Code]` is the riskiest part. Keep it small and close to `install.ps1`'s logic so debugging is a matter of diffing the two files.
