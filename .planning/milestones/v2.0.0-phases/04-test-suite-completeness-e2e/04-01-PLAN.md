## Task 1: GOTEST-01 — Gmail HTTP client tests

<read_first>
- `src/native-host/gmail.go` — `NewGmailClientWithBase`, `CreateDraft`, error paths (401, non-200, decode error, network error).
- `src/native-host/protocol.go` — `MailMessage` struct shape.
</read_first>

<action>
Create `src/native-host/gmail_test.go` with a table-driven test
`TestGmailClient_CreateDraft` that spins up an `httptest.Server`, points
`NewGmailClientWithBase` at it, and asserts the happy path plus four
failure paths:
  1. `200 OK` with `{"id":"abc123"}` → `CreateDraft` returns `"abc123", nil`.
  2. `401 Unauthorized` → error contains `"token expired"`.
  3. `500 Internal Server Error` with a body → error contains `"Gmail API error (500)"`.
  4. Server closed before call (network failure) → error contains `"failed to create draft"`.
  5. `200 OK` with non-JSON body → error contains `"failed to parse response"`.

For each case, additionally assert the request used `POST`, had the
`Authorization: Bearer <token>` header, and used the path `/drafts`. Build
a minimal `MailMessage` for the request body so `buildFullMIME` does not
fail.
</action>

- `grep -n "Bearer" src/native-host/gmail_test.go` matches at least once.

## Task 2: GOTEST-02 — buildFullMIME golden-file tests

<read_first>
- `src/native-host/gmail.go` — `buildFullMIME` function body, `formatRecipients`, `mimeEncodeHeader`, `base64Wrap`, boundary format string.
</read_first>

<action>
Create `src/native-host/mime_golden_test.go` with:
  - A package-level `var updateGoldens = flag.Bool("update", false, "regenerate MIME golden files")`.
  - A helper `normalizeMIMEBoundary(b []byte) []byte` that uses a regex to
    replace `go_mapi_<digits>` with `go_mapi_PID` so goldens stay stable.
  - A `TestBuildFullMIME_Golden` table-driven test with cases:
      1. `utf8_subject` — ASCII recipient, `Subject: Héllo Wörld`, plain body, no attachments.
      2. `attachment_spaces` — one attachment with filename `"report final.txt"`, written to `t.TempDir()`.
      3. `attachment_nonascii` — one attachment with filename `"résumé.pdf"`, written to `t.TempDir()`.
      4. `boundary_collision` — body text that contains the literal substring `go_mapi_` to ensure base64 encoding shields against collision (body is base64-encoded before boundary matching, so this is a regression guard against someone removing the encoding).
      5. `long_body` — plain body of ~12KB of repeated ASCII text.
      6. `empty_body` — empty body with a To recipient.

Each case calls `buildFullMIME(&mail)`, normalizes the boundary, and
compares against `testdata/mime/<case>.golden`. If `-update` is passed,
the golden is (re)written instead. Comparison uses `bytes.Equal`.

Generate the six `.golden` files by running `go test -update ./...` once
during plan execution and committing the resulting fixtures. Verify the
tests pass against the committed goldens via a second `go test` run
without `-update`.
</action>

<acceptance_criteria>
- `ls src/native-host/testdata/mime/` shows all six `.golden` files: `utf8_subject.golden`, `attachment_spaces.golden`, `attachment_nonascii.golden`, `boundary_collision.golden`, `long_body.golden`, `empty_body.golden`.
- `grep -n "updateGoldens" src/native-host/mime_golden_test.go` matches.
- `grep -n "normalizeMIMEBoundary" src/native-host/mime_golden_test.go` matches.
- `grep -n "go_mapi_PID" src/native-host/mime_golden_test.go` matches.
- `cd src/native-host && go test -run TestBuildFullMIME_Golden ./...` exits 0.
- Every `.golden` file is non-empty.
</acceptance_criteria>
