<objective>
Deliver EXT-06: the popup auto-detects when the host is installed after the user has seen the InstallPrompt. Transition MISSING → READY fires a one-time success toast (React Bootstrap Toast, NOT chrome.notifications), tracked via a session-scoped flag so it only shows once per session.

Purpose: Closes the install UX loop — no manual reload required, no repeated toasts on subsequent reconnects.
Output: Service worker tracks MISSING→READY edge and emits HOST_INSTALLED_TOAST exactly once. Popup renders a React Bootstrap Toast for ~5 seconds.
</objective>

         hostState = next;
         hostErrorMessage = opts.errorMessage;
         console.log('[go-mapi] hostState →', next, opts);
         broadcastToPopup({
           type: 'HOST_STATE',
           state: next,
           hostVersion: hostVersion || undefined,
           errorMessage: opts.errorMessage,
         });
         if (prev === 'MISSING' && next === 'READY' && !hasShownInstalledToast) {
           hasShownInstalledToast = true;
           persistInstalledToastFlag();
           broadcastToPopup({ type: 'HOST_INSTALLED_TOAST' });

       }
