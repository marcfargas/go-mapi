**Author `scripts/measure-ram.ps1`** — PowerShell 5+ compatible. Script must correlate go-mapi.exe with its msedgewebview2.exe child processes via Win32_Process ParentProcessId (REVIEWS HIGH — Get-Process alone does NOT expose PPID).

Script responsibilities:

1. Accept params: `-Session <string>` (session user identifier), `-Scenario <cold-start|idle-pre-webview|idle-post-webview>`, `-Iteration <int>`, `-OutputCsv <path>`.

2. **Multi-process correlation + Private WS measurement (per-session TOTAL metric per REVIEWS HIGH):**
```powershell
# Find go-mapi.exe processes owned by the current session user.
$sessionUser = $env:USERNAME
$goMapiProcs = Get-CimInstance Win32_Process -Filter "Name='go-mapi.exe'" |
    Where-Object { (Invoke-CimMethod -InputObject $_ -MethodName GetOwner).User -eq $sessionUser }

if (-not $goMapiProcs) {
    Write-Error "No go-mapi.exe process found for session user $sessionUser"
    exit 1
}

# For each go-mapi PID, find msedgewebview2.exe children via PPID.
foreach ($gm in $goMapiProcs) {
    $gmPid = $gm.ProcessId
    $wvChildren = Get-CimInstance Win32_Process -Filter "Name='msedgewebview2.exe' AND ParentProcessId=$gmPid"

    # Private Working Set via perf counter (D-01 — excludes shared pages).
    $gmWsMb = (Get-Counter -Counter "\Process(go-mapi)\Working Set - Private" -ErrorAction SilentlyContinue).CounterSamples[0].CookedValue / 1MB
    $wvWsMb = 0
    foreach ($wv in $wvChildren) {
        # Counter name for msedgewebview2 processes — may need instance disambiguation if multiple run.
        # Use the perf-counter instance index or fall back to the process's WorkingSetPrivate from Win32_Process
        # if perf-counter instance resolution is unreliable.
        $wvWsMb += ($wv.WorkingSetPrivateBytes / 1MB)   # fallback shape — adjust based on Win32_Process schema actually available
    }
    $totalWsMb = $gmWsMb + $wvWsMb

    # Append CSV row (REVIEWS HIGH mandatory artifact).
    $row = [PSCustomObject]@{
        iteration       = $Iteration
        session_user    = $sessionUser
        scenario        = $Scenario
        go_mapi_pid     = $gmPid
        go_mapi_ws_mb   = [math]::Round($gmWsMb, 2)
        webview2_ws_mb  = [math]::Round($wvWsMb, 2)
        total_ws_mb     = [math]::Round($totalWsMb, 2)
        timestamp       = (Get-Date).ToString('o')
    }
    $row | Export-Csv -Path $OutputCsv -Append -NoTypeInformation
}
```

The exact shape of `WorkingSetPrivateBytes` vs perf-counter per-instance resolution may need tweaking on the live VM — document the final approach in SUMMARY. The invariant is: for EACH row in the CSV, `total_ws_mb` correctly sums go-mapi.exe private WS + all its msedgewebview2.exe children's private WS owned by the same session user.
