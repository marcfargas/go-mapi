# Phase 7 — UI Design Contract

> Visual and interaction contract for Phase 7 (Wails Shell + RAM Gate). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** Phase 7 is a measurement/viability gate. The UI surface is intentionally minimal: one system tray icon with two variants, one main window containing a single live queue list (read-only). No per-email actions, no OAuth UI, no toasts — those land in Phases 8–9. This contract locks the visual primitives so that feature phases do not re-debate them.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Svelte desktop app — shadcn is React-only; not applicable) |
| Preset | not applicable |
| Component library | none (plain Svelte 5 components + hand-rolled CSS per RESEARCH.md §Frontend: "No Bootstrap CSS, no heavy components. Queue list is text.") |
| Icon library | none (Phase 7 has no in-window icons; tray icons are hand-authored PNG/ICO assets — see Tray Icon Assets below) |
| Font | System font stack: `"Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system, sans-serif` — zero bundle cost, native Windows look, aligns with RAM-gate discipline |

**Source:** RESEARCH.md §Frontend and §Bundle Hygiene lock Svelte 5 + plain CSS; CONTEXT.md scope forbids design-system adoption in this phase.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps (between subject and timestamp meta) |
| sm | 8px | Compact element spacing (queue row vertical padding) |
| md | 16px | Default element spacing (list item horizontal padding, window padding) |
| lg | 24px | Section padding (empty-state container) |
| xl | 32px | Reserved (not used in Phase 7 — kept for later phases) |

Exceptions: none. Phase 7 uses xs/sm/md/lg only; xl is declared for continuity but unused.

## Typography

Three sizes, two weights. Source: inferred from minimal-queue scope (D-05) using a conventional desktop-app ladder.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (sender, subject) | 14px | 400 (regular) | 1.5 |
| Meta (timestamp, empty-state body) | 12px | 400 (regular) | 1.5 |
| Heading (empty-state heading, window title bar label if any) | 16px | 600 (semibold) | 1.2 |

Rationale: 14px body matches Windows native app density (File Explorer, Settings). 12px meta is the minimum readable size for timestamps. 16px semibold is the single emphasis tier — no display size in Phase 7 (no marketing surfaces).

## Color

Windows-native light theme only. Dark theme is deferred (Claude's discretion per CONTEXT.md §decisions notes light/dark tray icon variants as optional — window theming follows the same deferral).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Main window background, queue list surface |
| Secondary (30%) | `#F3F3F3` | Row hover state, empty-state container background |
| Accent (10%) | `#0067C0` | Focus ring on keyboard-focused list row; tray icon idle glyph fill |
| Destructive | `#C42B1C` | Tray icon error-variant glyph fill; error-state text in window (if watcher init fails) |

Text colors (neutral, not counted in 60/30/10):
- Primary text: `#1A1A1A` (sender, heading)
- Secondary text: `#616161` (subject truncation, timestamp meta, empty-state body)
- Border hairlines: `#E5E5E5` (row separators)

**Accent reserved for:** (1) keyboard focus ring on the currently-focused queue row, (2) the idle-variant tray icon glyph. Nothing else. No accent-colored buttons, no accent links (there are no links in Phase 7).

**Destructive reserved for:** (1) error-variant tray icon glyph, (2) the single error-state message shown in the window body when the watcher fails to start or WebView2 bootstrap reports an error. No destructive buttons in Phase 7 (Quit lives only in the tray menu, not as a button).

Palette source: Windows 11 Fluent neutrals (`#FFFFFF`/`#F3F3F3`/`#1A1A1A`) + Windows accent default blue (`#0067C0`) + Windows system error red (`#C42B1C`). Rationale: matches the host OS without bundling a design system.

## Copywriting Contract

All strings are English (per user rule: external projects English everything). Strings are centralized for eventual i18n but not translated in Phase 7.

| Element | Copy |
|---------|------|
| Window title | `go-mapi` |
| Primary CTA | not applicable — no CTA buttons in Phase 7 (queue is read-only) |
| Queue-list column headers | not rendered (text-only rows; no table header to reduce visual weight and RAM-gate-neutral pixel count) |
| Queue row format | `{sender}` · `{subject}` · `{timestamp as "HH:mm" if today, else "MMM D"}` |
| Empty state heading | `No emails waiting` |
| Empty state body | `When a Windows app sends to mail, it will appear here.` |
| Error state heading | `Watcher stopped` |
| Error state body | `go-mapi can't watch %TEMP%\go-mapi\. Restart the app, or check app.log for details.` |
| WebView2-missing state (if detectable at window-first-show) | `Microsoft Edge WebView2 runtime is required. Install it from Microsoft and restart go-mapi.` |
| Tray menu: Show | `Show` |
| Tray menu: Quit | `Quit` |
| Tray tooltip (idle) | `go-mapi — watching for emails` |
| Tray tooltip (error) | `go-mapi — watcher stopped` |
| Destructive confirmation | not applicable — `Quit` has no confirmation dialog in Phase 7 (destructive actions with data loss do not exist; Quit does not lose queued emails because JSON files persist in `%TEMP%\go-mapi\`) |

**Destructive actions in Phase 7:** none. Quit is not destructive (files survive). Dismiss and Create-draft are Phase 9.

## Tray Icon Assets (Phase-7-specific)

Per CONTEXT.md §D-11, ship two variants only; has-queue is Phase 9.

| Variant | File | Glyph fill | Semantic meaning |
|---------|------|------------|------------------|
| Idle | `tray-idle.ico` (16px + 32px + 48px multi-res ICO) | `#0067C0` (accent) | App is running, watcher is healthy, queue may be empty or non-empty |
| Error | `tray-error.ico` (16px + 32px + 48px multi-res ICO) | `#C42B1C` (destructive) | Watcher failed to start, or WebView2 missing, or other recoverable-via-restart error |

Glyph shape: a stylized envelope mark (simple geometric — 2–3 paths, no gradients) so both fills read at 16px. Authored in SVG, exported to multi-resolution ICO. Stored under `src/app/frontend/static/tray/` or equivalent path decided by planner.

Light/dark auto-switching is Claude's discretion (CONTEXT.md §D-11) — if trivial, ship paired `-light` / `-dark` PNGs and pick based on `ShouldAppsUseDarkMode()`; otherwise ship one pair that reads on both.

## Window Layout (Phase-7-specific)

| Property | Value |
|----------|-------|
| Default size | 480 × 600 px |
| Min size | 360 × 400 px |
| Resizable | yes |
| Position persistence | deferred to later phase (CONTEXT.md §Claude's Discretion explicitly permits deferral) |
| Initial visibility | hidden (`Hidden:true`, `HiddenOnTaskbar:true` per research ARCHITECTURE.md) |
| Close button behavior | hide to tray (intercept `WindowClosing`, call `runtime.WindowHide()`, return true) |

Layout inside the window (single view, no routing):

```
┌─────────────────────────────────────────┐
│  [16px padding]                         │
│                                         │
│  Queue list (scrollable)                │
│  ├─ Row: 8px vertical × 16px horizontal │
│  │      14px sender · 14px subject      │
│  │      12px timestamp (right-aligned)  │
│  └─ 1px #E5E5E5 separator between rows  │
│                                         │
│  Empty state (when queue is empty):     │
│  centered, 24px padding                 │
│  16px/600 heading                       │
│  8px gap                                │
│  12px/400 body                          │
└─────────────────────────────────────────┘
```

No header bar, no footer, no sidebar, no toolbar. Phase 9 will add action buttons to rows.
