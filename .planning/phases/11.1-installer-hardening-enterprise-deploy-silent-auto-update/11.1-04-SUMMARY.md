# Phase 11.1 Plan 04: Silent Update Download + Verify + Atomic Swap Summary

**Status:** Completed
**Phase:** 11.1
**Plan:** 04
**Subsystem:** Auto-update

## substantive one-liner

Wired the actual silent-update behavior on top of the Plan 11.1-02 scaffold: download SHA256SUMS.txt + 3 release assets, verify each via go-selfupdate's ChecksumValidator BEFORE writing to disk, then atomically swap them in place via MoveFileEx with two-step rename-while-running (with 30s→5min exponential retry capped at 12h per D-14).

## Key Decisions

- **W6 — Option A (multi-asset swap)** confirmed per `11.1-03-AUDIT.md`. The pipeline downloads `go-mapi.exe`, `go-mapi-x64.dll`, `go-mapi-x86.dll`, verifies each against `SHA256SUMS.txt`, and per-asset `swapWithRetry`s into `$INSTDIR\go-mapi.exe`, `$INSTDIR\go-mapi.dll`, and `%ProgramFiles(x86)%\go-mapi\go-mapi.dll`.
- **errChecksumFailed sentinel + filename-only abort log.** go-selfupdate's `ChecksumValidator.Validate` returns errors containing both expected and found hex digests. Naively `%w`-wrapping that error and `%v`-logging the wrapper would leak digests into `update.log`, violating Pitfall 6 + threat T-11.1.04-06. Solution: `downloadAndVerify` swallows the validator's error and returns a fixed `errChecksumFailed` sentinel; the pipeline branches on `errors.Is(err, errChecksumFailed)` and logs `aborted: checksum mismatch` (no `%v`). The `verified asset FAILED for <filename>` line is the audit trail — and the filename is public manifest data.
- **Verify-BEFORE-write, not just verify-BEFORE-swap.** `downloadAndVerify` runs the validator on the in-memory body BEFORE calling `os.WriteFile`. An unverified asset never hits disk, which collapses the staged-tampering window from "between WriteFile and MoveFileEx (microseconds in a SYSTEM-only writable dir)" to "zero". Strengthens T-11.1.04-02 mitigation beyond the plan's bar.
- **time.Sleep, not select+time.After in swapWithRetry.** The retry loop has no `ctx` cancellation wired through it — the outer `for time.Now().Before(deadline)` is the abort signal. staticcheck S1000/S1037 collapse the single-case select to `time.Sleep`.
- **Multiple package-level test seams.** `silentHTTPClient` (httpDoer interface), `installRootOverride`, `programFiles32Override`, and the pre-existing `testBackoffOverride` form a coherent test-injection layer. All four are zero/empty in production and assigned via `t.Cleanup` teardown in tests. Lets the new `TestRunSilentUpdate_UpdateAvailable_FullPipeline` cover the *complete* download → verify → swap flow against canned bodies, replacing the Plan 11.1-02 stub that only asserted a deferred-log marker.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] errChecksumFailed sentinel to prevent Pitfall-6 log leak**
- **Found during:** Task 2 verification — initial impl wrapped the validator error via `%w` and logged `download/verify %s aborted: %v`, which propagated go-selfupdate's `expected "X", found "Y"` hex digests into `update.log`.
- **Issue:** Pitfall 6 + T-11.1.04-06 require update.log to contain no hex digests; the validator's error message embeds them by design.
- **Fix:** Introduced `errChecksumFailed` sentinel; `downloadAndVerify` returns ONLY this sentinel on validator rejection (the validator's actual error is dropped, but the filename-only `verified asset FAILED for X` line is logged first as the audit trail). The pipeline branches on `errors.Is(err, errChecksumFailed)` and logs `aborted: checksum mismatch` (no `%v`).
- **Files modified:** `src/app/updates_silent.go` (added `errors` import, sentinel definition, branch in pipeline loop)
- **Commit:** `02cc094`
- **Test coverage:** `TestRunSilentUpdate_UpdateAvailable_FullPipeline` now includes a hex-leak guard that scans the entire log for any 40+-char `[0-9a-f]` run and fails the test if one is found.

**2. [Rule 1 — Bug] staticcheck S1000/S1037 — collapse `select { case <-time.After(d): }` to `time.Sleep(d)`**
- **Found during:** post-Task-1 static analysis.
- **Issue:** Single-case select with only `time.After` is the staticcheck S1000/S1037 pattern; should be `time.Sleep` unless a parallel `case <-ctx.Done()` is wired.
- **Fix:** Collapsed to `time.Sleep(backoff)`. The outer `for time.Now().Before(deadline)` is the abort signal — no ctx-cancel was ever wired through `swapWithRetry`.
- **Files modified:** `src/app/updates_silent.go` (`swapWithRetry`)
- **Commit:** `02cc094`

## Threat Model Notes

The threat register from `11.1-04-PLAN.md` was honored:
- **T-11.1.04-02 (staged-file tampering)** — strengthened beyond the plan: validator runs on in-memory bytes BEFORE WriteFile, so an unverified asset never hits disk at all.
- **T-11.1.04-05 (DoS via large download)** — `io.LimitReader` caps each asset at 50 MB; manifest at 64 KB. Verified by `downloadCappedBody` returning explicit error when exceeded.
- **T-11.1.04-06 (info disclosure via update.log)** — Pitfall 6 enforced via `errChecksumFailed` sentinel + `// no hex` invariant verified by both grep and a runtime hex-leak guard in `TestRunSilentUpdate_UpdateAvailable_FullPipeline`.

No new threat surfaces introduced beyond those documented in the plan's `<threat_model>` block.
