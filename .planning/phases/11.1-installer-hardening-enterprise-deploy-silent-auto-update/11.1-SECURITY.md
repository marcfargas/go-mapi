## Cross-Plan Verification Notes

- **Pitfall 6 enforcement (no hex digests in update.log):** `grep -E "%x|hex\.|fmt\.Sprintf.*%[xX]" src/app/updates_silent.go` returns 0 matches. The log function at `src/app/updates_silent.go:266-269` writes "verified asset OK/FAILED for <filename>" — filename only, no digest bytes.
- **Verify-BEFORE-swap (V12):** `downloadAndVerify` at `src/app/updates_silent.go:257-274` calls `validator.Validate(manifestFilename, body, manifestBytes)` (in-memory) BEFORE `os.WriteFile(destPath, body, 0o644)`. Confirmed by reading sequencing in source: validate at line `:262`, log success at `:269`, then write at `:274`. No swap call appears before write.
- **MOVEFILE_DELAY_UNTIL_REBOOT explicitly absent (D-12):** `grep -c "MOVEFILE_DELAY_UNTIL_REBOOT" src/app/updates_silent.go` returns 0. Only `MOVEFILE_REPLACE_EXISTING` is used (lines `:336, :343, :348, :354`).
- **NSIS strict-bool /AUTOUPDATE parser (T-11.1.05-03):** `StrCmp $AutoUpdateFlag "1"` at `src/installer/go-mapi.nsi:116` (UI page skip) and `:744` (gate). Anything other than literal "1" treated as OFF.
- **Programmatic XML write supersedes PowerShell substitution (T-11.1.05-04 stronger-than-planned):** `src/installer/go-mapi.nsi:767-809` builds the task XML in-place via `FileWriteUTF16LE`. The `[regex]::Escape` defense planned in PLAN.md is moot — there is no PowerShell substitution to defend against. The fixed-string XML body interpolates `$INSTDIR` at NSIS compile-equivalent string-build time, not at shell-exec time.
- **No `## Threat Flags` sections in any 11.1-0N-SUMMARY.md** — executor confirmed no new attack surface beyond plan threat models. No unregistered flags to log.
- **SUMMARY contract honored:** all six summaries explicitly state "no new threat surfaces introduced beyond plan threat models".
