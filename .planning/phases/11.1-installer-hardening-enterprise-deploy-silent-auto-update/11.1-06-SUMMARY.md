# Phase 11.1 Plan 06: Enterprise-install docs + ROADMAP + REQUIREMENTS Summary

Closes Phase 11.1 with the documentation deliverables that align user-facing surfaces with the simplified scope locked in 11.1-CONTEXT.md (binary auto-update opt-in checkbox, SYSTEM Scheduled Task, SHA-256 verification via go-selfupdate ChecksumValidator, MoveFileEx atomic swap, no machine-wide YAML config, no tri-state install).

## What Shipped

### Task 1 — README.md ## Enterprise installation section (commit `0d7ab4b`)

Added a new H2 `## Enterprise installation` immediately after the existing consumer `## Install` section, with sub-sections covering:

- **Elevation and scope**: All Users only, UAC mandatory, MAPI handler is inherently machine-wide via `HKLM\SOFTWARE\Clients\Mail\go-mapi`, no "Just for me" option.
- **Unattended (silent) install**: `go-mapi-setup.exe /S /D=...` and `/AUTOUPDATE=1` syntax. Default `/AUTOUPDATE=0`.
- **Automatic updates**: Full Scheduled Task property table (name `go-mapi Auto Update`, SYSTEM principal, daily 03:00 ±30min, at-startup catch-up, `RunOnlyIfNetworkAvailable`, `StartWhenAvailable`, `MultipleInstancesPolicy=IgnoreNew`, `ExecutionTimeLimit=PT12H`); 5-step description of what `--update-check-silent` does (fetch SHA256SUMS → stage download → verify-before-write → MoveFileEx atomic swap → log version transition); explicit note that the running interactive instance is NOT restarted (next launch picks up the new binary).
- **Managing the Scheduled Task post-install**: `schtasks /change /tn ... /disable|/enable|/run|/query` examples + Task Scheduler UI path; idempotent re-install for upgrade-from-notify-only path.
- **Integrity verification**: stable SHA256SUMS.txt URL; one-line PowerShell `Get-FileHash` + `Invoke-WebRequest` snippet for manual verification; SignPath signing called out as additive defense-in-depth.
- **Multi-user RDS limitation**: carry-forward from Phase 10 D-19 — uninstaller scrubs running admin's profile + machine-wide locations only; documents the manual workaround for shared RDS hosts.
- **Privacy posture**: explicit two-target network-call enumeration (GitHub Releases + Google APIs); no telemetry / no content retention / `update.log` records version transition + download success-or-failure only.

A single cross-link line lands at the bottom of the existing `## Install` section (above the new H2): `> For unattended or managed deployments (RDS, MSI/SCCM/Intune fleet roll-outs), see [Enterprise installation](#enterprise-installation) below.`

Consumer-install copy stays intact per D-19. No rewrites of pre-existing language.
