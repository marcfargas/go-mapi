# Plan 03-02: Installer release workflow (signing + publish)

## Goal

A new, additive GitHub Actions workflow `.github/workflows/installer-release.yml` that, on tag push `v*`, builds the DLL + host binary + installer, optionally signs them via SignPath, and attaches `go-mapi-setup.exe` to the tag's GitHub Release at the stable `latest/download` URL. SignPath signing is gated on `secrets.SIGNPATH_API_TOKEN`; when the secret is absent, the workflow produces an unsigned installer and publishes it anyway.

This plan does NOT modify the existing `.github/workflows/release.yml` (scope discipline — additive only).

<action>
Create `.github/workflows/installer-release.yml` with:

```yaml
name: Installer Release

on:
  push:
    tags:
      - 'v*'
  workflow_dispatch:
    inputs:
      version:
        description: 'Version for manual builds (e.g. 0.0.0-dev)'
        required: false
        default: '0.0.0-dev'

concurrency:
  group: installer-release-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: write
  id-token: write  # SignPath action requires id-token write for OIDC (harmless if signing is gated off)

jobs:
  build-installer:
    name: Build (and sign) installer
    runs-on: windows-latest

    env:
      # SignPath config — populated from repository secrets once SignPath approval lands.
      # While any of these are empty, the signing steps skip via the `if:` gate and
      # the workflow produces an unsigned installer (SIGN-03 fallback).
      SIGNPATH_API_TOKEN: ${{ secrets.SIGNPATH_API_TOKEN }}
      SIGNPATH_ORG_ID: ${{ secrets.SIGNPATH_ORG_ID }}
      SIGNPATH_PROJECT_SLUG: ${{ secrets.SIGNPATH_PROJECT_SLUG }}
      SIGNPATH_SIGNING_POLICY_SLUG: ${{ secrets.SIGNPATH_SIGNING_POLICY_SLUG }}

    steps:
      - uses: actions/checkout@v4

      - name: Resolve version
        id: version
        shell: bash
        run: |
          if [[ "${GITHUB_REF}" == refs/tags/v* ]]; then
            TAG="${GITHUB_REF#refs/tags/}"
            SEMVER="${TAG#v}"
          else
            SEMVER="${{ github.event.inputs.version || '0.0.0-dev' }}"
            TAG="v${SEMVER}"
          fi
          echo "TAG=${TAG}" >> "$GITHUB_OUTPUT"
          echo "SEMVER=${SEMVER}" >> "$GITHUB_OUTPUT"
          echo "Resolved version: ${SEMVER} (tag ${TAG})"

      # --- Build interceptor DLL ---
      - name: Install MinGW, Ninja, CMake
        run: |
          choco install mingw ninja cmake --no-progress -y
          echo "C:\ProgramData\chocolatey\lib\mingw\tools\install\mingw64\bin" >> $env:GITHUB_PATH

      - name: Build interceptor DLL
        working-directory: src/interceptor
        run: .\build.ps1 -Config Release -Clean

      # --- Build native host ---
      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.21'

      - name: Build native host
        working-directory: src/native-host
        shell: pwsh
        run: |
          go mod tidy
          go build -ldflags "-s -w -X main.Version=${{ steps.version.outputs.SEMVER }}" -o build/go-mapi-host.exe .

      # --- Sign DLL + host before installer compile (gated on token) ---
      - name: Stage unsigned binaries for signing
        shell: pwsh
        run: |
          New-Item -ItemType Directory -Path sign-input -Force | Out-Null
          Copy-Item src/interceptor/build/bin/go-mapi.dll sign-input/
          Copy-Item src/native-host/build/go-mapi-host.exe sign-input/

      - name: Upload unsigned binaries artifact (for SignPath input)
        if: env.SIGNPATH_API_TOKEN != ''
        id: upload-unsigned
        uses: actions/upload-artifact@v4
        with:
          name: unsigned-binaries
          path: sign-input/
          if-no-files-found: error

      - name: SignPath — sign DLL and host
        if: env.SIGNPATH_API_TOKEN != ''
        uses: SignPath/github-action-submit-signing-request@v1
        with:
          api-token: ${{ env.SIGNPATH_API_TOKEN }}
          organization-id: ${{ env.SIGNPATH_ORG_ID }}
          project-slug: ${{ env.SIGNPATH_PROJECT_SLUG }}
          signing-policy-slug: ${{ env.SIGNPATH_SIGNING_POLICY_SLUG }}
          artifact-configuration-slug: go-mapi-binaries
          github-artifact-id: ${{ steps.upload-unsigned.outputs.artifact-id }}
          wait-for-completion: true
          output-artifact-directory: sign-output

      - name: Replace unsigned binaries with signed ones
        if: env.SIGNPATH_API_TOKEN != ''
        shell: pwsh
        run: |
          if (Test-Path sign-output/go-mapi.dll) {
            Copy-Item sign-output/go-mapi.dll src/interceptor/build/bin/go-mapi.dll -Force
            Write-Host "Replaced DLL with signed version"
          } else {
            throw "Signed DLL not found at sign-output/go-mapi.dll"
          }
          if (Test-Path sign-output/go-mapi-host.exe) {
            Copy-Item sign-output/go-mapi-host.exe src/native-host/build/go-mapi-host.exe -Force
            Write-Host "Replaced host binary with signed version"
          } else {
            throw "Signed host binary not found at sign-output/go-mapi-host.exe"
          }

      - name: Note unsigned fallback
        if: env.SIGNPATH_API_TOKEN == ''
        shell: pwsh
        run: |
          Write-Host "::warning title=Unsigned build::SIGNPATH_API_TOKEN is not set — producing unsigned installer (SIGN-03 fallback path)."

      # --- Build installer ---
      - name: Install Inno Setup 6
        run: choco install innosetup --no-progress -y

      - name: Compile installer
        shell: pwsh
        run: |
          & "C:\Program Files (x86)\Inno Setup 6\iscc.exe" `
            /DGOMAPIVersion=${{ steps.version.outputs.SEMVER }} `
            src\installer\go-mapi.iss
          if (-not (Test-Path 'src\installer\dist\go-mapi-setup.exe')) {
            throw 'Installer compile produced no go-mapi-setup.exe'
          }
          Get-Item 'src\installer\dist\go-mapi-setup.exe' | Format-List Length, LastWriteTime

      # --- Sign installer (post-build, gated on token) ---
      - name: Upload unsigned installer artifact (for SignPath input)
        if: env.SIGNPATH_API_TOKEN != ''
        id: upload-unsigned-installer
        uses: actions/upload-artifact@v4
        with:
          name: unsigned-installer
          path: src/installer/dist/go-mapi-setup.exe
          if-no-files-found: error

      - name: SignPath — sign installer
        if: env.SIGNPATH_API_TOKEN != ''
        uses: SignPath/github-action-submit-signing-request@v1
        with:
          api-token: ${{ env.SIGNPATH_API_TOKEN }}
          organization-id: ${{ env.SIGNPATH_ORG_ID }}
          project-slug: ${{ env.SIGNPATH_PROJECT_SLUG }}
          signing-policy-slug: ${{ env.SIGNPATH_SIGNING_POLICY_SLUG }}
          artifact-configuration-slug: go-mapi-installer
          github-artifact-id: ${{ steps.upload-unsigned-installer.outputs.artifact-id }}
          wait-for-completion: true
          output-artifact-directory: signed-installer

      - name: Replace unsigned installer with signed one
        if: env.SIGNPATH_API_TOKEN != ''
        shell: pwsh
        run: |
          if (Test-Path signed-installer/go-mapi-setup.exe) {
            Copy-Item signed-installer/go-mapi-setup.exe src/installer/dist/go-mapi-setup.exe -Force
            Write-Host "Replaced installer with signed version"
          } else {
            throw "Signed installer not found"
          }

      # --- Upload installer as a workflow artifact (always) ---
      - name: Upload final installer artifact
        uses: actions/upload-artifact@v4
        with:
          name: go-mapi-setup
          path: src/installer/dist/go-mapi-setup.exe
          if-no-files-found: error

      # --- Publish to GitHub Releases (tag push only) ---
      - name: Publish installer to GitHub Release
        if: startsWith(github.ref, 'refs/tags/v')
        uses: softprops/action-gh-release@v2
        with:
          name: go-mapi ${{ steps.version.outputs.TAG }}
          tag_name: ${{ steps.version.outputs.TAG }}
          body_path: .github/release-template.md
          append_body: true
          files: src/installer/dist/go-mapi-setup.exe
          prerelease: ${{ contains(steps.version.outputs.TAG, 'alpha') || contains(steps.version.outputs.TAG, 'beta') || contains(steps.version.outputs.TAG, 'rc') }}
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Comments inside the file document that:
- This workflow complements (does not replace) `release.yml`.
- Signing is gated on `SIGNPATH_API_TOKEN` per SIGN-03; missing secret → unsigned fallback path runs.
- The installer is always published with the stable filename `go-mapi-setup.exe` so the `latest/download` URL is stable per SIGN-04.
- Release notes come from `.github/release-template.md` (Plan 03-03 creates this file).
</action>

## Notes

- SignPath action parameter names follow the v1 action's documented schema. If the action rejects any parameter at runtime, the fallback path (no secret) still works because the whole step is gated.
- The `append_body: true` flag on `action-gh-release` lets the release notes template be additive to whatever release the existing `release.yml` may have already created with `generate_release_notes: true`. Both workflows can run on the same tag without conflict.
