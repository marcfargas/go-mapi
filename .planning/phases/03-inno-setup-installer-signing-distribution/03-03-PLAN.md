# Plan 03-03: Release notes template and extension URL swap

## Goal

(a) Create `.github/release-template.md` — the release notes body that the installer-release workflow attaches to every GitHub Release. It must include SmartScreen click-through guidance so a non-technical user can install the unsigned fallback build (SIGN-05).

(b) EXT-07: swap the placeholder `INSTALLER_DOWNLOAD_URL` constant in `src/extension/src/popup/InstallPrompt.tsx` for the final stable URL. Because Phase 2 runs in parallel, `InstallPrompt.tsx` may not exist in this worktree at execute time. Handle all three cases per Phase 3 CONTEXT D-25.

## Tasks

### Task 1: Create `.github/release-template.md`

<read_first>
- `.planning/REQUIREMENTS.md` SIGN-05 (line 47) — SmartScreen guidance required in release notes
- `.planning/phases/03-inno-setup-installer-signing-distribution/03-CONTEXT.md` D-24 (release notes template content list)
</read_first>

<action>
Create `.github/release-template.md` with sections:

1. **One-line summary** at the top, plain text.
2. **Download** section: direct link to `https://github.com/marcfargas/go-mapi/releases/latest/download/go-mapi-setup.exe` (the stable URL).
3. **Installation** section: 3 steps — download, run, click through the one UAC prompt.
4. **If Windows SmartScreen blocks the installer** section: explains the "Windows protected your PC" dialog that appears for unsigned builds (and may still appear for newly signed builds until Microsoft's reputation engine learns the cert), and the click-through: "More info" link → "Run anyway" button. State plainly that this is expected for the unsigned fallback build while the project's SignPath Foundation review is in progress. Keep copy non-technical and reassuring.
5. **What's installed** section: bullet list of install locations and what the uninstaller removes (references INST-02..06 in prose form so a user knows what they're agreeing to).
6. **Uninstall** section: one line — "Use 'Add or remove programs' and select go-mapi, or run the uninstaller at `C:\Program Files\go-mapi\unins000.exe`."
7. **Support** section: link to https://github.com/marcfargas/go-mapi/issues.
8. **Privacy** section: one paragraph restating the privacy-first posture (no telemetry, no long-term storage, no network calls except Gmail API).

English-only. No emojis. Markdown-compatible with GitHub Releases rendering.
</action>
