Add `execSync` to imports:

```typescript
import { execSync } from 'child_process';
```

Replace the existing `stampManifestVersion` function with:

```typescript
function stampManifestVersion(): Plugin {
  return {
    name: 'stamp-manifest-version',
    writeBundle({ dir }) {
      const extPkg = JSON.parse(readFileSync(resolve(__dirname, 'package.json'), 'utf-8'));
      const manifestPath = resolve(dir!, 'manifest.json');
      const manifest = JSON.parse(readFileSync(manifestPath, 'utf-8'));

      // Strip any prerelease/build metadata for base version
      const baseVersion = extPkg.version.replace(/[-+].*$/, '');

      if (process.env.NODE_ENV === 'production') {
        // CWS requires integer-only semver: use base version only
        manifest.version = baseVersion;
      } else {
        // Dev builds: {version}-dev+{commithash} (per D-07)
        let hash = 'unknown';
        try {
          hash = execSync('git rev-parse --short HEAD', { encoding: 'utf-8' }).trim();
        } catch {
          // not in a git repo or git not available
        }
        manifest.version = `${baseVersion}-dev+${hash}`;
      }

      writeFileSync(manifestPath, JSON.stringify(manifest, null, 2) + '\n');
    },
  };
}
```

Key changes:
1. `resolve(__dirname, 'package.json')` -- reads from `src/extension/package.json` (own directory), not root (per D-06, VER-01)
2. Production builds: strip prerelease/build metadata to produce CWS-compliant `X.Y.Z` format
3. Dev builds: append `-dev+{commithash}` for local identification (per D-07)
4. `process.env.NODE_ENV === 'production'` is set by Vite during `vite build` (the `npm run build` script runs `tsc && vite build` which sets production mode)

Do NOT modify any other part of `vite.config.ts` -- the rollup config, plugins array, and build options remain unchanged.
