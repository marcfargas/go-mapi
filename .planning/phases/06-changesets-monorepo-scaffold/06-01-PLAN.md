```json

  "$schema": "https://unpkg.com/@changesets/config@3.0.0/schema.json",

  "fixed": [],
  "linked": [],
```

- `commit: false` -- the GitHub Action handles commits; setting true would double-commit
- No `publish` command -- Phase 6 is scaffold only, no publishing

Keep the auto-generated `.changeset/README.md` as-is (explains changeset workflow to contributors).
