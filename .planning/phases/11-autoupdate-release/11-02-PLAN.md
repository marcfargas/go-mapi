<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App update state → tray UI | Backend update metadata crosses into tray-rendered labels and actions |
| Tray click handlers → App bindings | User input from the tray triggers persisted settings writes and manual checks |
| Notification action → browser | External browser navigation opens release URLs under user control |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Elevation of privilege | Tray update action | mitigate | Keep Download action browser-only; never spawn installer or quit helper per D-03. |
| T-11-02-02 | Denial of service | systray thread affinity | mitigate | All `systray.*` calls remain inside the tray goroutine; background code only signals refresh. |
| T-11-02-03 | Information disclosure | Tray labels | mitigate | Expose version/last-checked status only; do not surface raw network errors or internal stack traces. |
| T-11-02-04 | Tampering | Manual-check action spam | mitigate | Manual action reuses bounded backend check path from 11-01 rather than custom ad hoc network code. |
</threat_model>
