## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend update state → frontend UI | Update metadata crosses from Wails into rendered Svelte components |
| User click → external browser | Release and installer links navigate outside the app |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Spoofing | Update links in UI | mitigate | Render only backend-provided GitHub release and stable installer URLs; do not accept arbitrary user input. |
| T-11-03-02 | Denial of service | Banner/panel noise | mitigate | Render UI only for update-available state; failures remain silent per D-04. |
| T-11-03-03 | Tampering | Frontend state drift | mitigate | Hydrate from `GetUpdateState()` and subscribe to one backend event rather than maintaining a parallel client-side source of truth. |
</threat_model>
