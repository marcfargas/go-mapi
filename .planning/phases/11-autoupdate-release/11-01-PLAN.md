<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App backend → GitHub Releases API | Untrusted network metadata crosses into the desktop app |
| Background goroutine → persisted settings | Update cadence reads persisted user preferences and timestamps |
| App bindings/events → tray/frontend consumers | Update state crosses from Go into UI surfaces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01-01 | Tampering | GitHub release metadata | mitigate | Parse only the fields required for version comparison and links; ignore release-body HTML/markup as executable input. |
| T-11-01-02 | Denial of service | Startup update check | mitigate | Enforce opt-out and 24h cadence; failures are bounded and log-only so startup continues. |
| T-11-01-03 | Information disclosure | Logging | mitigate | Log only high-level update-check error categories/URLs; never log OAuth secrets or release-body content. |
| T-11-01-04 | Tampering | Persisted settings writes | mitigate | Keep the existing atomic single-file write path and single-writer invariant in `settings.go`. |
| T-11-01-05 | Elevation of privilege | Updater flow | mitigate | Explicitly keep update detection notify-only; no download, no installer launch, no binary replacement per D-03. |
</threat_model>
