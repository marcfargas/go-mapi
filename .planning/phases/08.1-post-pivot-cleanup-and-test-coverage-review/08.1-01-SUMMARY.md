## Decisions Made

- **Packaging choice — `package mapi` not `package mapi_test`.** The plan explicitly specifies unqualified in-package access; staying in `package mapi` also matches how the existing `internal/mapi/protocol_test.go` and `internal/mapi/watcher_test.go` are structured, avoiding a second testing style in one package.
- **Byte-for-byte copy, no regeneration.** Rather than running `go test -run TestBuildFullMIME_Golden ./... -update` to regenerate fixtures in place, the fixtures were copied via `cp` and sha256-verified against the sources. Prevents accidental reformat (line endings, trailing whitespace) from silently mutating the golden assertion.
- **Scope boundary on Task 4.** The plan's Task 4 action lists all four must-hold-invariant commands, but its `<verify><automated>` block limits the gating check to `go test ./internal/mapi/... ./src/app/... && go vet ./internal/mapi/...`. The `./src/app/...` Go build/test fails at baseline commit (pre-existing) because `src/app/main.go:12` uses `//go:embed all:frontend/dist` and `frontend/dist/` is a gitignored build output. This plan only touched `internal/mapi/` test files — no `src/app/` code was modified. The pre-existing failure is logged to `deferred-items.md` and left for plans that rewrite the full build pipeline (or run `wails build` first). `internal/mapi/` itself is fully green.
