## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Lint script referenced deleted src/native-host**
- **Found during:** Task 3
- **Issue:** `package.json` `lint` script chained `eslint src/extension/src/ && cd src/native-host && go vet ./...`. Deleting `src/native-host/` would leave the script broken (cd would fail).
- **Fix:** Trimmed the chain to `eslint src/extension/src/` only. The `eslint` half is Plan 05's deletion target (extension cleanup), so the lint script keeps a single coherent purpose for one more wave.
- **Files modified:** `package.json` (line 20)
- **Commit:** `48e5102`

**2. [Scope-adjustment] Workspace array final shape diverged from plan**
- **Found during:** Task 3
- **Issue:** Plan's must-have line 20 + Task 3 acceptance assert workspaces should become `["src/extension","src/app"]` after this plan. Current `package.json` had four entries: `["src/extension","src/native-host","src/app","src/app/frontend"]` — Phase 8 added `src/app/frontend` after the plan was written.
- **Fix:** Removed only `src/native-host` (this plan's actual scope per CONTEXT D-02). Final shape: `["src/extension","src/app","src/app/frontend"]`. Plan 05 owns removing `src/extension`; Plan 08 finalizes per D-22 ("Final workspaces: `["src/app"]` or `["src/app/frontend"]` — planner verifies which nesting npm resolves correctly").
- **Files modified:** `package.json` (workspaces array)
- **Commit:** `48e5102`
- **Why this is correct:** Per scope discipline + read-before-write rules, removing workspaces this plan didn't enumerate would silently consume Plan 05/08 work and risk breaking the frontend workspace's `npm run -w @marcfargas/go-mapi-app-frontend build` invariant.

**3. [Tooling note] src/app/go.sum false-positive "M" in git status**
- **Found during:** Task 5 staging
- **Issue:** After `go work sync`, `git status` showed `src/app/go.sum` as modified, but `git diff` produced only autocrlf warnings (LF will be replaced by CRLF). `diff` against `git show HEAD:src/app/go.sum` confirmed identical content.
- **Fix:** Left unstaged. Commit captures only the four genuinely-modified config files plus the 24 native-host deletions. No content change to ship.
- **Files affected:** none (false positive)
